Drivers and passengers

Every login is written to a users document. Choosing a role adds the account to either the passengers or drivers collection. Connect a Firebase project below to store them in the cloud — until then the same collections live in this browser.

Connect Firebase

Firebase Console → Project settings → Your apps → Web. Paste the six keys. Enable Email/Password auth and Cloud Firestore (test mode).
