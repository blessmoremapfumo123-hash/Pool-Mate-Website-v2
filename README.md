# PoolMate

Corridor pooling for Lusaka — rides, cargo, food and delivery.

## For the lecturer — HTML files

The assignment website (open by clicking an HTML file) lives in **[website/](website/)**.

Start here: [website/index.html](website/index.html)

| File | Page |
| --- | --- |
| `website/index.html` | Home |
| `website/login.html` | Log in / sign up |
| `website/role.html` | Passenger or driver |
| `website/dashboard.html` | Book a ride |
| `website/drive.html` | Driver jobs |
| `website/database.html` | Firebase collections: passengers & drivers |

Firebase setup: [website/FIREBASE.md](website/FIREBASE.md)

## Live app

The full product is this TanStack Start app (login, booking, driver mode, wallet). After you sign in and pick a role, the account is stored in the **passengers** or **drivers** directory (same collections as the HTML site).
